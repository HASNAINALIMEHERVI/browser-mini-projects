About this personal project

Math Function Explorer is a deterministic JavaScript learning project by Hasnain Ali Mehervi. It includes arithmetic, statistics, approximate unit conversions, basic circuit formulas and small linear systems. It does not use an AI model.

Trigonometric inputs use radians. Variance is population variance. Month and year conversions use average durations, not calendar arithmetic. Floating-point rounding and near-singular matrices can affect results; verify engineering calculations independently.
